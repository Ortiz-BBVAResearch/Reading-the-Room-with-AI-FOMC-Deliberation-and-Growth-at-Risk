# Suggested JME data-repository fields

These are draft values based on the manuscript and Supplementary Material. The repository link remains blank until a public deposit exists.

- **Link to data repository:** `PENDING — insert the public HTTPS landing-page URL after deposit`
- **Repository name:** `Zenodo` (suggested; choose this only if the authors deposit there)
- **Source of data:** `Original data` (the article reports author-generated indices, estimates and forecast results; cite/reference the underlying public and licensed inputs in the documentation)
- **Title of the data set:** `Replication data and code for Reading the Room with AI: FOMC Deliberation and Growth-at-Risk`

The title is 98 characters, below the 200-character limit. Do not submit the URL placeholder as a link.
